| ② | 顺时针转动臂，收回动臂缸 | 动臂缸全缩 | 斗杆、铲斗 |

## 3. 原八段遗漏了什么

原斗杆扫描直接沿用①末的铲斗角，E215 的 ψ≈22.222°，因此绕 B 的半径为：

```text
|BT| = √(armLength² + bucketRadius² + 2·armLength·bucketRadius·cosψ)
     ≈ 4329.814439 mm
```

③先使 B–C–T 同向共线，④保持 ψ=0 扫描斗杆，半径变为 `armLength+bucketRadius = 2900+1504 = 4404 mm`。这达到给定 B 点下斗杆与齿尖串联的最大长度，补齐原低位扫描漏掉的外侧区域。

只改变动臂角、斗杆相对角、铲斗角时，齿尖分别绕 A、B、C 作圆弧。在当前预设的②→③、③→④、④→⑤接点，共线条件让相邻圆弧切线同向。旧文把遗漏处约 14.673° 的折角与深度缺口解释为正常，这一结论已更正。修复添加的是实际单缸运动，并未用平滑曲线替代轨迹。

## 4. 验证方法与复现

```bash
node tools/test.mjs
node tools/verify-envelope-sequence.mjs
node tools/verify-envelope-sequence.mjs --json
```

独立序列工具直接读取生产模型的原始点列，采用 0.1°步距、`tol=0`；根据规定动作独立建立期望端点，再从圆心与齿尖坐标反解每个采样点的活动关节角。

逐段检查：

1. 起始三缸长度符合全伸 / 全缩 / 全缩。
2. 九段编号和点索引连续；每段圆心固定，齿尖采样点的半径保持不变。
3. 活动关节的转向正确，活动油缸按要求单调伸出或缩回。
4. 用世界坐标下油缸两端销轴中心距核对缸长，不动的两根油缸长度保持不变。
5. 全部缸长位于有效行程内，终点达到规定的全缩/全伸值。
6. ①③⑤共线且点序分别为 A–C–T / B–C–T / A–T–C；⑨与起点闭合。
7. ④半径等于斗杆长加齿尖半径，并超过旧扫描半径。

| 机型 | 原始轨迹点数 | 九段检查 | 共线、闭合与斗杆最大外伸 |
|---|---:|---|---|
| 20 吨级示例 | 8210 | 全部通过 | 通过 |
| E215 | 8146 | 全部通过 | 通过 |

圆弧半径、固定缸长、共线距离和闭合的数值检查容差为 1e-6 mm。此容差用于核对浮点几何计算，不表示真机测量或制造精度。JSON 结果同时写入本地 `.verify/envelope-sequence-results.json`，该临时结果不入库。

本次 Node 测试 163/163 通过，其中包络 20/20 通过；将相同包络回归放到旧实现上有 6 项失败，确认能检出漏段。浏览器自检 124 项中 123 项通过，唯一失败是既有的最小回转半径 `<30 ms` 时序阈值；旧版同环境也在该项失败，详见 [开发与测试](开发与测试.md)。

## 5. 深度交叉校验与适用条件

五项作业尺寸仍按各自姿态定义单独计算。E215 的动臂最低姿态为 α≈−40.174804°，B–C–T 竖直向下需要 Δ≈−49.825196°；该角位于斗杆行程 [−156.304320°, −33.316076°] 内，因此④包含深度指标的定义姿态。

| E215 深度口径 | 深度 / mm |
|---|---:|
| 旧八段路径，0.1°、不简化 | 6222.007335 |
| 九段路径，0.1°、不简化 | 6296.193862 |
| 九段默认显示路径，0.75°、1 mm 简化 | 6295.827394 |
| 定义姿态解析值 | 6296.193939 |

高精度采样与解析值相差约 0.000077 mm；默认显示路径相差约 0.367 mm。九段修复消除了原约 74.2 mm 的几何缺口，剩余差异属于采样与简化误差。

严格完成③要求零角在铲斗行程内，并能从①末顺时针到达。生产算法将③目标限制为 `clamp(0, ψmin, psi1)`：零角超出顺时针可达范围时截到可达端点；①末已经顺时针越过零角时，③保持原姿态并保留零长度段。①、⑤的共线目标也受行程限制；自定义参数导致目标截断时，绘图仍保留规定动作的可达部分，但严格共线验证不能视为通过。

该验证证明两种当前预设符合九步规定并补齐这次遗漏，不证明填充区域内每一点都可达，也不证明任意自定义参数下九段构造就是全部可达姿态的严格边界。全局极值还需结合各关节范围及对应姿态是否可达来核对。
