# 参数口径

> 这个项目最容易踩坑的地方不是算法，而是**参数的坐标基准**：同一个「铰点位置」，从 A 量、从 B 量、从 C 量，正负号完全不同。
> 本文把 48 项参数的口径、自检项和三个最常见的坑一次说清。

---

## 1. 三套坐标基准

所有「沿杆」类坐标都遵守同一条设计原则：**自末端销孔起算、向根部为负**。这样加长动臂或斗杆时，安装点会自动跟着末端销孔一起走，不会掉到杆件外面去。

| 基准 | 原点与取向 | 用它的参数 |
|---|---|---|
| **相对 A**（整机坐标偏移） | 动臂根部铰点 A；ΔX 向前为正、ΔY 向上为正 | `boomCylBodyDX/DY`（动臂油缸缸筒端装在转台前部，ΔX>0、ΔY<0） |
| **动臂坐标系** | 原点 A，+x 指向 B（动臂轴线），+y 为动臂上方 | `boomCylRodAlong/Perp`（活塞杆端铰在动臂下侧，Perp<0）<br>`armCylBodyAlong/Perp`（**自 B 起算**，向根部为负、上方为正） |
| **斗杆坐标系** | 原点 B，+x 指向 C（斗杆轴线），+y 为斗杆上方 | `armCylRodAlong/Perp`（真机在 B 点后方、斗杆上平面：Along<0、Perp>0）<br>`bktCylBodyAlong/Perp`、`bktBellAlong/Perp`（**自 C 起算**，向根部为负） |
| **铲斗坐标系** | 原点 C，+x 指向斗齿尖 T | `bktEAlong/Perp`（连杆–铲斗铰点 E） |

一句话记忆：**缸筒端永远跟着它装的那根杆件的「末端销孔」走**（斗杆油缸缸筒端跟着 B、铲斗油缸缸筒端与摇杆铰点跟着 C），活塞杆端跟着它推动的那根杆件走。

## 3. 参数是怎么被消费的

`params.js` 是**唯一的参数元数据来源**，只改它一处，下面这些全部自动跟着变：

| 消费方 | 用法 |
|---|---|
| 界面参数面板 `controls.js` | 按 `PARAM_SPEC` 自动生成滑块 + 数字框（分组、区间、步长、单位、提示都取自元数据） |
| 范围收敛 `sanitizeParams()` | 任何来源（URL、预设、手输）的参数都被夹进合法区间 |
| 合法性校验 `validateParams()` | 阻断性错误（`errors`）+ 提示性告警（`warnings`），见下节 |
| 分享链接 `share.js` | `SHORT_KEYS` 短键 + **只写与预设不同的字段**，所以默认状态的链接最短 |
| 参数表 `chart-table.js` | 表格行、铰点坐标对照表 |
| 文档 | 本文的参数表由 `tools/gen-param-table.mjs` 生成 |

## 4. 校验与自检

### 4.1 阻断性检查（`validateParams` → `errors`，界面红字并保留上一次有效结果）

- 动臂长度 / 斗杆长度 / 铲斗销轴至斗齿尖距离 / 三根油缸的行程 / 连杆长度 必须 > 0
- 动臂铰点高度不得超过整条工作装置链长（否则永远够不到地面）
- **关节角必须能由油缸行程解出**：动臂仰角、斗杆相对转角、铲斗相对转角三者都必须解得出有限值
- 动臂仰角范围 ≥ 15°
- 铲斗相对转角范围 ≥ 60°

### 4.2 提示性告警（`warnings`）

- 动臂仰角上限 > 80°（真机受驾驶室与油缸限位约束，到不了这么高）
- 铲斗相对转角范围 > 220°（超出常规铲斗行程）
- 斗杆转角范围覆盖不到「最大挖掘深度姿态」所需的 −90°−αmin
- 铲斗转角范围覆盖不到「最大卸载高度姿态」所需的 ψ
- **油缸布置自检**（`verifyCylinderLayout`）逐项检查，见下

### 4.3 油缸布置自检项

| 检查项 | 口径 |
|---|---|
| 动臂油缸缸筒端 | 在 A 点前下方（ΔX > 0 且 ΔY < 0） |
| 动臂油缸活塞杆端 | 在动臂两端点连线的另一侧（真机在动臂下侧，故 Perp < 0） |
| 斗杆油缸活塞杆端 | 在 B 后方、斗杆上平面（Along < 0 且 Perp > 0） |
| 斗杆油缸缸筒端 | 在动臂上表面且在动臂范围内（自 B：−动臂长 < Along < 0，Perp > 0） |
| 铲斗油缸缸筒端 / 摇杆铰点 D | 在斗杆上方且在斗杆范围内（自 C：−斗杆长 < Along < 0，Perp > 0） |
| 摇杆 / 连杆长度 | 分别在 0.08~0.38 倍、0.12~0.55 倍斗杆长 |
| 连杆–铲斗铰点 E | 在斗背板上（相对 C：−0.35~0 R3、0.2~0.75 R3） |
| 装配支 | 斗杆油缸活塞杆端**全程**在动臂两端点连线 A–B 上方 |
| 伸出方向 | 动臂缸伸出 → 抬起；斗杆缸伸出 → 收拢（挖掘方向）；铲斗缸伸出 → 收斗 |
| 行程 / 安装距比例 | 动臂 ≥ 15%，斗杆 ≥ 30%，铲斗 ≥ 30%，且 < 115% |
| 干涉 | 斗杆油缸不与动臂本体相交，铲斗油缸不与斗杆本体相交（按截面厚度近似的矩形带，末端 6% 与杆端 200 mm 已豁免，另留 20 mm 建模容差） |

## 5. 三个最常见的坑

### 5.1 为什么「连杆–铲斗铰点 垂直斗齿」调到 536 以下就报红字？

**不是界面限制，也不是物理上做不到**，而是模型的一条硬约束被卡住，且卡得极其精确。

铲斗转角只能由铲斗油缸的「安装距 + 行程」反解，而求解器要求 ψ 轴上存在**一条单调行程段**，其缸长范围**完整覆盖**整段行程（20 吨级机型 默认 `1343.7 ~ 2531.3 mm`）。把 E 往下调，四连杆在同样行程下能达到的极限缸长会变小：

| `bktEPerp` | 单调段能达到的最大缸长 | 能覆盖全伸位 2531.3？ |
|---|---|---|
| 539 | 2532.9 mm | ✅ 余 1.6 mm |
| 537 | 2531.9 mm | ✅ 余 0.6 mm |
| **536** | **2531.4 mm** | ✅ **余 0.1 mm** |
| **535** | **2530.8 mm** | ❌ **差 0.5 mm** |

差这零点几毫米 → 「全伸 = 收斗位」这个端点解不出 ψ → 报「铲斗相对转角无法由油缸行程解出」。

**想再往下调**，动下面任意一项即可（实测把 E 压到 500 mm 也能通过）：安装距 `bktCylClosed` ≈ −20 mm、行程 `bktCylStroke` ≈ −20 mm，或摇杆 `bktRockerLen` ≈ +20 mm。

### 5.2 滑块的步长与数字框的步长不一样

长度类参数的滑块步长是 5 mm（例如 553 往下的刻度是 550 / 545 / 540 / **535**），而右侧数字框的步长是 1 mm。所以要精确输入 536、535 这种整数，用**数字框**，别用滑块拖。

### 5.3 改哪些参数不影响作业尺寸？

「整机外形」这一组（履带长度/宽度/高度、离地间隙、整机高度、平台前端外伸、动臂与斗杆截面宽、尾部回转半径）**不参与运动学计算**，只影响绘图外观与最小回转半径。参数面板里这一组的提示也是这么写的。

## 6. 参数从哪来

只有厂家公开样本指标时，20 吨级示例采用三步反解：

```
样本标称项（四项作业尺寸 + 最小回转半径）
   │  tools/fit-preset.mjs        反解整机几何：动臂 / 斗杆 / 斗容 / 铰点位置
   ▼
标定好的角度范围（αmin/αmax、Δmin/Δmax）
   │  tools/setup-cylinders.mjs   按机型尺度构造油缸与四连杆，反算安装距 / 行程 / 安装点
   ▼
完整参数集 → 写进 presets.js → node tools/calibrate.mjs 复核偏差
```

已有机型的油缸与连杆数据按资料录入；x20t 的对应数据仍是可替换的示例值。`presets.js` 同时保留 E215 收到的原始尺寸串，便于核对坐标映射。

### 6.1 E215 参数来源与派生角

E215 的动臂、斗杆、铲斗齿尖半径、油缸安装点和行程、摇杆/连杆尺寸及斗杆/铲斗缸径与杆径按收到的资料录入。该机型没有厂家标称作业尺寸用于对标，`nominal` 与 `calibration` 均为空。整机外形、斗容、压力、背压、效率等未提供字段沿用示例默认值。

| 油缸 | 全缩 / 全伸长度（mm） | 全缩 / 全伸反解角（°） |
|---|---|---|
| 动臂 | 1790 / 3025 | α = −40.174804 / 68.807794 |
| 斗杆 | 2110 / 3650 | Δ = −33.316076 / −156.304320 |
